Selenium essentials

Start

Browser lifecycle

from selenium import webdriver

driver = webdriver.Chrome()
driver.get("https://example.com")

print(driver.title)
print(driver.current_url)

driver.quit()
Source

Read the loaded page

html = driver.page_source
body = driver.find_element(By.TAG_NAME, "body")
print(body.text)

page_source gives HTML. element.text gives visible text.

Find

One vs many

element = driver.find_element(
    By.ID, "login"
)

elements = driver.find_elements(
    By.CSS_SELECTOR, ".card"
)

find_element returns one WebElement; find_elements returns a list.

Inspect

Text, tag, attributes

element.text
element.tag_name

element.get_attribute("href")
element.get_attribute("class")
element.get_attribute("outerHTML")
Act

Interact

element.click()
element.clear()
element.send_keys("UAV landing")

Typical for search boxes, forms, buttons, filters, and dynamic pages.

Import

By locator API

from selenium.webdriver.common.by import By

Prefer Selenium 4 style:

driver.find_element(By.XPATH, "...")

Not the old find_element_by_xpath() style.

Waiting for dynamic content

Quick but crude

import time
time.sleep(5)

Useful while debugging, but fixed sleeps are slower and less reliable.

Preferred: explicit wait

from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC

wait = WebDriverWait(driver, 10)

element = wait.until(
    EC.presence_of_element_located((By.ID, "result"))
)

Useful expected conditions

presence_of_element_locatedvisibility_of_element_locatedelement_to_be_clickable

Use explicit waits when JavaScript loads results after the initial page response.

BeautifulSoup essentials

Parse

Create the soup

from bs4 import BeautifulSoup

soup = BeautifulSoup(
    html,
    "html.parser"
)
Find

Find tags

soup.find("a")
soup.find_all("a")
soup.find(id="main")
soup.find("div", class_="card")
CSS

CSS selectors

soup.select_one(".card")
soup.select(".card a")
soup.select('a[href*="/document/"]')
Text

Get text

tag.text
tag.get_text()
tag.get_text(strip=True)

strip=True removes surrounding whitespace.

Attributes

Safe attribute access

tag["href"]      # may raise

tag.get("href")  # returns None if absent
Navigate

Nearby elements

tag.parent
tag.children
tag.next_sibling
tag.previous_sibling

Practical patterns

Safe loop over links

for tag in soup.find_all("a"):
    url = tag.get("href")
    if url and "/document/" in url:
        print(url)

Inspect one Selenium result

element = driver.find_element(By.XPATH, "...")
print(element.tag_name)
print(element.text)
print(element.get_attribute("outerHTML"))
Rule of thumb: use BeautifulSoup when the data is already in the HTML. Use Selenium when JavaScript loads the content or you need to interact with the page.
